# 🌾 StardewValleyDex

> Um aplicativo desktop offline-first e utilitário de consulta rápida para a **Stardew Valley Wiki**.

---

## 📌 Sobre o Projeto

**StardewValleyDex** é um aplicativo desktop construído com **Tauri** que armazena localmente o conteúdo da Stardew Valley Wiki. Ele permite navegar por todas as páginas, tabelas, imagens e guias instantaneamente sem depender de conexão com a internet, além de realizar sincronizações automáticas das atualizações da wiki em segundo plano.

---

## 🛠️ Tecnologias Principais

- **Desktop Framework:** Tauri (Rust + Web)
- **Database:** SQLite (Armazenamento offline do HTML e metadados)
- **Updater:** Background Worker com MediaWiki API (`api.php`)
